# Express JWT та Cookie Проект

## Опис функціональності
Сервер на базі Node.js та Express.js реалізує:
1. Роздачу статичних файлів із папки `public` (включаючи `favicon.ico`).
2. Збереження налаштужень теми оформлення за допомогою `cookie-parser`.
3. Автентифікацію користувачів із використанням JSON Web Tokens (JWT), що зберігаються в захищених `httpOnly` cookies.
4. Підтримку шаблонізаторів Pug та EJS із підключеною іконкою сайту.

## Встановлення та запуск
1. Клонуйте репозиторій.
2. Встановіть залежності: `npm install`
3. Запустіть сервер: `npm start`
4. Відкрийте в браузері: `http://localhost:3000`
